# easyclaw-community

A shared home for the **easyClaw** community.

This is where users, builders, and trailblazers can share the things that make easyClaw more useful: **skills, templates, examples, docs, recipes, and real-world workflows**.

If you’ve built something handy, this is a place to put it so others can use it, learn from it, and improve on it.

## What’s in here?

This repo is intended to grow into a practical community toolbox for the easyClaw and easyNode.ai ecosystem.

Typical contents include:

- **Skills** — reusable AgentSkills for common tasks and integrations
- **Templates** — starter kits and scaffolds to help people build faster
- **Examples** — working patterns people can copy and adapt
- **Docs** — guides, notes, and best practices
- **Recipes** — opinionated solutions for real operational problems
